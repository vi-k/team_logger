## Правила, которые легко нарушить

- **`README.ru.md` правится тем же коммитом, что `README.md`.** Из
  публикации его убирает одна строка в `.pubignore` — не удалять.
- **Разделы README 1–11 не перенумеровывать:** на «README §10» ссылаются три
  комментария в `test/loggable/sanitizer_cross_review_test.dart`. Новое
  добавлять довеском (сейчас есть §12 и §13).
- **В записи ревью вердикт ровно один и текущий**, прозу находки не трогать
  (`docs/conventions.md`, «Записи ревью»).
- **В `docs/backlog.md` агент не пишет** — только читает и удаляет сделанное.
- **По-русски ровно три места:** `docs/`, `README.ru.md`, `AGENTS.md`
  (+`CLAUDE.md`, который только подключает его). Всё остальное, включая
  комментарии в конфигах, — по-английски. Исключение — 12 строк
  синтетических данных в `tool/playground_data.dart`: это данные, а не
  комментарии.
- **Политики заморозки API** — `docs/conventions.md`, раздел «Заморозка API
  на 1.0». Главное: **консольный рендер не замораживается**; формат JSONL —
  замораживается и версионируется (`FileLogCodec.formatVersion`).
- **Состояние API-справочника проверять на
  `pub.dev/documentation/<пакет>/latest/`**, а не локальным `dart doc`: он
  не разрешает элементы зависимостей, и на этом уже была снята неверная
  находка.
- **Списки ограничений стареют молча.** Переписывая или перенося их —
  проверять запуском, а не переносить на веру.
