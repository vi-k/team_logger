# Настройка восстановления после обрыва сессии

## Что сделано

Точка входа для всех агентов — `AGENTS.md` (его читает Codex; Claude Code
приходит туда через `CLAUDE.md`, где теперь только `@AGENTS.md`). В нём:
порядок действий в новой сессии, карта документов и границы между ними,
правила поддержания handoff, рабочий цикл, команды и язык документов.

Документы разведены по ролям:

- `docs/handoff.md` — только текущее состояние: где мы, что не
  закоммичено, статус проверок, известные ограничения, следующий шаг.
- `docs/backlog.md` — записи владельца; агент туда не пишет, только берёт
  в работу и удаляет сделанное.
- `docs/architecture.md` — устойчивое устройство пакета: точки входа,
  пайплайн, модули, инварианты санитайзера.
- `docs/conventions.md` — код, публичный API и версии, коммиты, документы,
  именование записей в `docs/records/`, работа с ревью.
- `docs/records/` — история: спеки, планы, отчёты, ревью.

`.claude/settings.json` (новый, проектный) получил хук `SessionStart`,
печатающий `docs/handoff.md` в контекст на старте, резюме и после
`/clear` — чтобы шаг «прочитать handoff» не зависел от того, вспомнит о
нём агент или нет. У Codex аналога нет, но `AGENTS.md` он читает сам.

## Миграция существующего

`docs/superpowers/{plans,specs}` переехали в `docs/records/` под новые
имена `YYYY-MM-DD[N]-name-kind.md`, каждому файлу добавлена шапка
«Состояние на …» с текущим статусом работы и коммитом. Внутренние ссылки
на старые пути переписаны.

Корневой `TODO.md` смешивал пожелания владельца и техдолг из ревью;
владелец выбрал разделение. Пожелания и пункты по README ушли в
`docs/backlog.md`, три находки ревью (wide-символы, висящее двоеточие при
полном дропе `LoggableData`, config при `builder`/`mapBuilder`) — в раздел
«Известные ограничения» `docs/handoff.md`. Сам `TODO.md` удалён; ссылка на
него убрана из `.pubignore`, вместо неё добавлен `AGENTS.md`.

## Чего эта работа не касалась

В рабочем дереве оставались правки прошлой сессии — запись 0.7.0 в
`CHANGELOG.md` и версия в `pubspec.yaml`. Они не коммитились вместе с
документацией: релиз 0.7.0 — отдельное решение владельца. На момент
работы `dart test` — 396 зелёных, `dart analyze` чист по коду.
