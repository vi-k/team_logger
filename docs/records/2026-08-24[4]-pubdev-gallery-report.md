# Галерея скриншотов на pub.dev

Состояние на 2026-08-24. Закрывает находку 7 из
`2026-08-23[7]-user-eyes-review.md`.

## Почему передумали

В самой находке я оценил цену в **+400 КБ к архиву** и на этом основании
советовал не делать. Обе половины оценки оказались неверны.

**Выгода больше, чем «галерея на странице пакета».** В разметке поиска
pub.dev есть `screenshot-carousel`, `screenshot-thumbnail`,
`screenshot-description` и кнопки перелистывания — объявленные скриншоты
показываются каруселью **в списке результатов поиска**, то есть до того, как
человек решил открыть пакет. Для пакета, чей главный аргумент — как выглядит
вывод, это и есть нужная секунда.

Картинки README при этом видны и сейчас: pub.dev проксирует их через
`external-images.pub.dev` с GitHub raw (проверено на опубликованной 0.6.0).
Но только внутри README, ниже по странице.

**Цена в семь раз меньше.** Считал по PNG. Это ANSI-кадры — плоские цвета и
резкий текст, ровно то, что **lossless** WebP сжимает в разы. Пиксели те же:

| Кадр | PNG | WebP |
| --- | --- | --- |
| `quick_start_1` | 247 КБ | 30 КБ |
| `gallery_1` | — | 15 КБ |
| `gallery_2` | — | 13 КБ |
| `trace_1` | 61 КБ | 11 КБ |

Архив: **184 → 262 КБ**. Спецификация pub.dev разрешает до 10 скриншотов и
в собственном примере использует `.webp`.

## Кадры: два взяты как есть, два сняты заново

`quick_start_1` и `trace_1` владелец принял без правок.

`data_1` и `loggable_1` в галерею не годились, и по одной причине: **в
README у картинки есть текст вокруг, в галерее — нет.** Обе построены на
сравнении, которое без прозы не читается.

- `data_1` — две строки, первая для сравнения (обычная интерполяция). В
  галерее лишняя.
- `loggable_1` — три строки: обычный `toString`, `Loggable`, `freezed`.
  Нужна только вторая, и без подписи «(Loggable)».

Владелец: оставить по одной строке, но **расширить объём данных** и **сразу
показать вложенность**.

Так появилась девятая группа — `example/bin/readme_examples/gallery.dart`,
кадры `gallery_1` (вложенные мапы, список с длиной, глубинная раскраска
скобок) и `gallery_2` (объект, который сам решает, как печататься: вложенный
объект, единицы измерения у числа, список со счётчиком). Кадров стало 45.

Две вещи всплыли при съёмке:

- приватные имена классов **протекают в вывод**: `_Person(name: …)`. Классы
  кадра пришлось сделать публичными;
- при 100 столбцах данные обрывались огрызком `.4}` на четвёртой строке —
  данные подрезаны так, чтобы кадр укладывался в три строки.

## Устройство

`scripts/gallery.sh` берёт четыре PNG из `screenshots/` и пережимает
`cwebp -lossless` в `gallery/`. Каталог отдельный не для красоты:
`.pubignore` закрывает `screenshots/` целиком, а синтаксис gitignore **не
позволяет вернуть файл из исключённого каталога**, поэтому положить
галерею рядом с кадрами нельзя.

`--check` проверяет, что файлы на месте и не старше своих PNG. Орфан здесь —
картинка, которой больше нет в `pubspec.yaml`.

`cwebp` стал зависимостью конвейера.
