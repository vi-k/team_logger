# Спека: раскладка по умолчанию у `ConsoleLogPrinter`

Состояние на 2026-08-23. Источник — находка 1 в
`2026-08-23[7]-user-eyes-review.md`. Решение владельца: умолчание для
`rows`, ширина `maxLength: 120`.

## Задача

`rows` — единственный обязательный параметр `ConsoleLogPrinter`. Из-за него
`ConsoleLogPrinter()` не компилируется, и первый запуск пакета требует
руками собрать раскладку. При этом `theme` уже необязателен и по умолчанию
`LogMainTheme.defaultActiveTheme` — то есть мнение о виде пакет себе уже
позволяет, и асимметрия ничем не обоснована.

## Решение

`static const List<LogRow> ConsoleLogPrinter.defaultRows` и
`this.rows = defaultRows` вместо `required this.rows`.

Имя — по образцу `LogMainTheme.defaultActiveTheme`, а не отдельный класс
`LogRows`: ради одной константы новую сущность не заводим.

Содержимое — раскладка из Quick Start, чтобы README и умолчание совпадали:

```dart
static const List<LogRow> defaultRows = [
  LogRow(
    maxLength: 120,
    children: [
      LogNum(),
      LogLevelName.short(),
      LogTime.onlyTime(),
      LogPath(),
      LogTraceId(),
      LogMessage(),
    ],
    tail: [LogTags()],
  ),
];
```

## Почему 120, а не `LogRow.singleLine`

`singleLine` не выбирает произвольного числа и не добивает строку
пробелами, но и не показывает ни переноса с маркером, ни правого `tail` —
того, ради чего пакет и нужен. Умолчание, которое прячет продукт, плохое
умолчание. 120 совпадает с Quick Start.

## Почему это не решает находку 6

Автоширина требует `stdout.terminalColumns`, то есть `dart:io`, а
`ConsoleLogPrinter` живёт в платформонезависимом `team_logger.dart`
(проверено: собирается `dart compile js`). Автоопределение может появиться
только в `team_logger_io.dart` и только явным хелпером. Находки развести.

## Совместимость

Превращение обязательного именованного параметра в необязательный —
**не ломающее** изменение: весь существующий код продолжает компилироваться.
0.7.0 ещё не выпущена, поэтому запись идёт в её раздел `CHANGELOG.md`, без
подъёма версии.

## Тесты

- `ConsoleLogPrinter()` конструируется и печатает лог;
- умолчание даёт ожидаемый состав: номер, короткий уровень, время, путь,
  trace id, сообщение и теги в правом `tail`;
- явный `rows:` перекрывает умолчание;
- `defaultRows` константна и разделяется между экземплярами (identical).
