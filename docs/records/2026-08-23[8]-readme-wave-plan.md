## Ограничения, из которых вырос порядок работ

1. **Разделы 1–11 не перенумеровывать.** На «README §10» ссылаются три
   комментария в `test/loggable/sanitizer_cross_review_test.dart` (строки
   11, 41, 142). Новые разделы идут довеском: §12, §13 и `## Known
   Limitations` перед `## License`.
2. **`README.ru.md` правится тем же коммитом.** Не после и не отдельно —
   `docs/conventions.md`, раздел про перевод.
3. **Оглавление правится вместе с разделами**, иначе якоря разъезжаются.
4. **Вывод показываем картинкой, а не комментарием в коде** — соглашение
   README. Если новому примеру нужен вывод, кадр объявляется в
   `example/bin/readme_examples/`, и группа пересобирается
   `scripts/screenshots.sh --only <группа>`. Без вывода обходимся текстом:
   лишний кадр — лишние 43+1 байт-в-байт проверки.
5. **В README не пишем, как готовилась документация** (`conventions.md`):
   «измерено», «проверено прогоном» — это в записи, не в README.

## Порядок

Три коммита, в каждом `README.md` и `README.ru.md` вместе:

1. A + F + D — врезка про минимум, имя `logger_builder`, добивка пробелами.
2. C + G — релизные сборки, Flutter.
3. B + E — свой publisher, известные ограничения.

После каждого: `dart analyze`, `dart test`, `dart format`,
`scripts/screenshots.sh --check`, `dart pub publish --dry-run` (в листинге
не должно быть `README.ru`).

## Что переносится в `## Known Limitations`

Из `docs/architecture.md`, раздел «Известные ограничения», — только
пользовательское, без внутренней кухни:

- текст из `LoggableView` не обезвреживается безопасным режимом ANSI;
- сообщение, текст ошибки, `units` и `DateTime` конфигом не управляются;
- все свойства builder'а, выброшенные правилом, оставляют висящее
  двоеточие (`login: `); у multi-data это починено, у `LoggableData` нет;
- `Loggable.builder(config:)` и `mapBuilder(config:)` свой config корневой
  замене не передают;
- локалезависимого форматирования чисел нет вовсе;
- size settings — не hard caps (уже сказано в §9, здесь только ссылка).

Остальное (UAX #29, iOS) уже в README или относится к устройству пакета.
