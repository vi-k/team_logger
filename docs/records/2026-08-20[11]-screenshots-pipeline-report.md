# Конвейер скриншотов: пилот

## Что теперь есть

Кадр — именованная функция; файл группы отдаёт карту в общую
`runFrames` (`example/lib/readme_examples/frames.dart`):

```dart
final frames = <String, Frame>{
  'trace_1': _searchTrace,
  // …
};

void main(List<String> args) => runFrames(frames, args);
```

Контракт аргументов: `--list` печатает имена, `<имя>` исполняет один кадр
под фиксированными часами, без аргументов — все подряд с заголовками (так
файл вёл себя и раньше). Неизвестное имя — сообщение в stderr и код 2.

`scripts/screenshots.sh` обходит группы, снимает каждый кадр отдельным
процессом и пишет два файла: `screenshots/<кадр>.ansi` и
`screenshots/<кадр>.png`. Режимы: по умолчанию всё, `--only <группа>`,
`--check`.

`init_log.dart` и `default_log.dart` получили `tags: {'log'}` — тот самый
тег, который владелец добавлял руками перед съёмкой. Теперь код
воспроизводит картинки, а не приблизительно на них похож.

## Пилот подтвердил главное

Все четыре кадра `trace` совпали со своими картинками — отличается только
время, ставшее синтетическим. Включая подпись под `trace_4` («lazy-4, not
lazy-6»), которая лежала в файле закомментированной и теперь печатается
кадром: раз она на картинке, а картинка производная от кода, печатать её
обязан кадр.

Воспроизводимость оказалась даже лучше расчётной. Спека рассчитывала
только на стабильный `.ansi` — на случай, если рендер PNG зависит от
машины или шрифтов. По факту **и PNG стабилен**: md5 всех четырёх картинок
после повторного прогона тот же. То есть пересборка не даёт шума вообще,
и `git status` после неё пуст, если кадры не менялись.

Шаг часов вышел ровно 37 мс между строками — значит пакет спрашивает
`clock.now()` один раз на лог. Подбирать шаг вручную не понадобилось.

## Отклонение от плана: определение переведённой группы

План предлагал спрашивать у каждого файла `dart run … --list` и
пропускать тот, кто ответил ошибкой или пустотой. На прогоне выяснилось,
что это не работает: непереведённый файл на `--list` **не падает** — он
игнорирует аргумент, печатает все свои логи и выходит с нулём. Скрипт
принял этот вывод за список кадров и попытался создать файлы с именами из
ANSI-строк; получил `File name too long`.

Заменено на положительную проверку: группа считается переведённой, если в
файле есть `runFrames(`. Плюс второй заслон — каждое имя из `--list`
проверяется на `^<группа>_<номер>$`, и несовпадение останавливает скрипт с
ошибкой, а не молча.

Побочная выгода: непереведённые файлы больше не запускаются вовсе, а
раньше на каждый прогон исполнялись целиком впустую.
